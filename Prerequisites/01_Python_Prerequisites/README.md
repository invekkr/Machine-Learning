# Python Prerequisites for Machine Learning

Python is the lingua franca of modern Machine Learning. However, you do **not** need to become a full-stack Python software developer before starting ML. You only need to master the specific subset of Python, data structures, and scientific libraries used to load, clean, transform, and model data.

This section breaks down Python programming into 8 focused, beginner-friendly learning modules.

## 🎯 How to Study These Modules

1. **Start with 01_Python_Basics** if you are brand new to Python syntax.
2. **Move through 02_NumPy and 03_Pandas** — these are the foundational data manipulation workhorses you will use daily.
3. **Review 04_Data_Handling and 06_Scikit_Learn** to understand the object-oriented structure of machine learning workflows.
4. Each folder contains `notes.md` with beginner explanations and a hands-on `.ipynb` notebook to practice.
